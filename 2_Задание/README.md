Мой прогноз (до запуска Python)
Выражение	Прогноз	Результат Python	Совпало?
2 + 3 * 4	14	14	✅
(2 + 3) * 4	20	20	✅
17 // 5	3	3	✅
17 % 5	2	2	✅
-7 // 2	-3	-4	❌ (была ошибка в прогнозе)
Объяснение различий
1. Приоритет операций (для первых двух выражений)

2 + 3 * 4 — умножение выполняется раньше сложения: 2 + 12 = 14.

(2 + 3) * 4 — скобки меняют порядок: 5 * 4 = 20.

Различий с Python нет, так как правила приоритета стандартные.

2. Целочисленное деление // и остаток % (для 17 // 5 и 17 % 5)

17 // 5 = 3, потому что 5 · 3 = 15 ≤ 17, а 5 · 4 = 20 > 17.

17 % 5 = 2, потому что 17 − 15 = 2.

Проверка связи: 17 = 5 · 3 + 2.

3. Главное различие — -7 // 2

Я интуитивно предположил -3 (просто «отбросить дробную часть» от -3.5), но Python выдаёт -4.

Причина: оператор // в Python выполняет округление вниз (floor division), а не «отбрасывание дробной части» (truncation).

-7 / 2 = -3.5

Округление вниз (к меньшему числу): -4

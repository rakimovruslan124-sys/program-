
## 1. Частоты слов

`word_counts(text)` — возвращает словарь `{слово: количество}`:

- приводит текст к нижнему регистру;
- разбивает по любым пробельным символам (`str.split()`);
- срезает символы `.,!?;:` с краёв каждого слова;
- пропускает слова, ставшие пустыми после среза;
- для пустого текста возвращает `{}`.

`sorted_pairs(counts)` — возвращает список пар `(слово, количество)`,
отсортированный по алфавиту.

## 2. Учебные интересы

`common_topics(first, second)` — общие темы (пересечение множеств),
`all_topics(first, second)` — все уникальные темы (объединение множеств).
Обе возвращают отсортированный список. Темы уже в нижнем регистре,
сравнение точное. Дубликаты во входных списках автоматически
устраняются множествами.

## 3. Запись и пара

- `make_record()` создаёт словарь `{"title": "Python", "hours": 20}`,
  затем меняет `hours` и добавляет `completed = False`.
- `title_hours_pair(record)` строит кортеж `(title, hours)`,
  который затем распаковывается в две переменные.

### Почему запись удобно представить словарём

1. **Именованные поля.** Ключи `title`, `hours`, `completed` документируют
   смысл данных — код читается как обычный текст: `record["hours"]`.
   В списке или кортеже пришлось бы помнить позиции.

2. **Изменяемость.** Словарь можно дополнять новыми полями без переписывания
   всех мест, где он используется: `record["completed"] = False`
   добавляет поле «на лету». Кортеж неизменяем, а список не даёт имён.

3. **Порядок не важен.** Доступ по ключу не зависит от порядка полей,
   поэтому добавление нового поля не ломает существующий код.

4. **Естественная сериализация.** Словарь напрямую отображается
   в JSON-объект, что удобно для сохранения и передачи записей.

5. **Кортеж — когда нужна неизменяемость и компактность.**
   Для фиксированной пары (например, `(title, hours)` при распаковке
   `title, hours = pair`) кортеж удобнее: он защищён от случайного
   изменения и сразу распаковывается.

Итого: **словарь — для изменяемой записи с именованными полями,
кортеж — для фиксированной пары значений.**
